# Questões do BeeCrowd

Este repositório reúne as questões que resolvo no Beecrowd durante o curso de Sistemas de Informação na UFAC.

Além de manter minhas soluções organizadas, quero deixar registrado aqui um pouco da forma como penso e programo ao longo da graduação.

Se alguma dessas questões estiver sendo útil para você, use minhas soluções como referência. Talvez você encontre uma forma diferente de pensar sobre o problema, mas não necessariamente a melhor. Tente entender a lógica e construir a sua própria solução.

Bons estudos!
